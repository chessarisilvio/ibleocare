Rilevazione Intelligente

I Sensori Capacitivi

I sensori capacitivi misurano l'umidità del suolo sfruttando le variazioni nella capacità elettrica del terreno. A differenza dei vecchi sensori resistivi (che si ossidano rapidamente), i sensori capacitivi non hanno parti metalliche esposte, garantendo una vita operativa di anni senza degradazione del segnale.

Precisione ±2% di umidità volumetrica
Lettura stabile a qualsiasi pH del suolo
Compatibile con terreni argillosi, sabbiosi e torbosi
Campionamento ogni 60 secondi (configurabile)
Sensore ambientale DHT22

Rileva temperatura e umidità dell'aria con precisione ±0.5°C e ±2% HR, fondamentale per il monitoraggio di serre e campi aperti.

FASE 2

Trasmissione via MQTT

MQTT (Message Queuing Telemetry Transport) è il protocollo di comunicazione per eccellenza dell'IoT. Nato in ambienti industriali a bassa larghezza di banda, è perfetto per microcontrollori embedded con risorse limitate.

// Topic MQTT
ibleo/dispositivo_ID/sensori/umidita
// Payload JSON
{
"umidita": 67.3,
"temperatura": 24.1,
"timestamp": "2026-04-01T14:23:11Z"
}
Latenza sub-secondo
<1 KB per messaggio
QoS 0/1/2 supportato

FASE 3

Analisi e Azione Automatica

Il server Node.js riceve i dati MQTT, li valida, li archivia nel database PostgreSQL e li rende disponibili alla dashboard web real-time via WebSocket.

Ricezione & Validazione

Node.js verifica l'integrità del payload JSON e scarta i valori anomali tramite outlier detection semplice: letture fuori range fisico vengono ignorate prima dell'archiviazione.

Archiviazione PostgreSQL

Ogni lettura viene persistita con timestamp, ID dispositivo e valori. Questa base dati è il motore dei grafici storici: 30 giorni di andamento in un click.

Alert & Notifiche

Se l'umidità scende sotto la soglia configurata dall'utente, il sistema invia automaticamente una notifica push (Web Push API) o email. Zero ritardi, zero sorprese.

Nota: L'attivazione automatica dell'irrigazione (via relè WiFi) è una feature della versione Pro prevista per il 2027.
